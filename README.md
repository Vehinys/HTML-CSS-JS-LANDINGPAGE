# Kucra Agency - Landing Page

Bienvenue sur le dépôt du projet **Kucra Agency**. Ce projet est une **Landing Page** (page d'atterrissage) moderne et responsive pour une agence créative fictive.

Ce site a été conçu dans un but éducatif pour mettre en pratique et consolider des compétences fondamentales en développement web front-end.

## 📋 Description

Le projet présente une vitrine professionnelle pour une agence ("Kucra Agency") comprenant plusieurs sections types d'un site d'entreprise moderne. L'accent est mis sur le design visuel, l'interactivité et l'adaptabilité sur différents supports (ordinateurs, tablettes, mobiles).

## ✨ Fonctionnalités

- **Design Responsive** : Le site s'adapte à toutes les tailles d'écran.
- **Menu de Navigation** :
  - Barre de navigation "Sticky" (fixe) lors du défilement.
  - **Menu Burger** animé pour la version mobile.
- **Interactivité** :
  - Bouton **Retour en haut (Scroll to Top)** qui apparaît lors du défilement.
  - Effets de survol (hover) sur les cartes, boutons et liens.
  - Défilement fluide (smooth scrolling) entre les sections.
- **Sections du site** :
  - **Accueil** : Hero header avec formulaire d'inscription.
  - **Features** : Présentation des services.
  - **Client** : Logos des partenaires.
  - **Works/Team** : Présentation de l'équipe et compteurs statistiques.
  - **Pricing** : Tableaux de prix comparatifs.
  - **Blog** : Extraits d'articles récents.
  - **FAQ** & **Footer**.

## 🛠 Technologies Utilisées

Ce projet a été réalisé sans framework lourd, utilisant uniquement les technologies standards du web :

- **HTML5** : Structure sémantique de la page.
- **CSS3** :
  - Mise en page avec Flexbox.
  - Gestion des couleurs, typographies (Google Fonts: Poppins) et ombres.
  - Media queries pour le responsive design.
  - Animations et transitions CSS.
- **JavaScript (Vanilla)** :
  - Manipulation du DOM.
  - Gestion des événements (click, scroll).
  - Logique du menu burger et du bouton "Scroll to Top".
- **Font Awesome** : Icônes vectorielles (v6.4.0).

## 🚀 Installation et Utilisation

Aucune installation complexe (npm, build, etc.) n'est nécessaire.

1.  **Cloner le dépôt** (ou télécharger les fichiers) :
    ```bash
    git clone https://github.com/votre-utilisateur/HTML-CSS-JS-LANDINGPAGE-1.git
    ```
2.  **Ouvrir le site** :
    - Double-cliquez simplement sur le fichier `index.html` pour l'ouvrir dans votre navigateur web préféré.
    - Ou utilisez une extension comme "Live Server" sur VS Code pour un rechargement automatique.

## 📂 Structure des Fichiers

- `index.html` : Le fichier principal contenant la structure HTML.
- `style.css` : La feuille de style gérant tout le design et la mise en page.
- `script.js` : Le fichier Javascript gérant l'interactivité.
- `IMAGE/` : Dossier contenant les ressources graphiques (images, svg).

## 🎓 Objectifs d'Apprentissage

Ce projet a permis de travailler sur les points suivants :

- **HTML** : Utilisation des balises sémantiques (`header`, `nav`, `section`, `article`, `footer`).
- **CSS** : Maîtrise des propriétés `display`, `position`, `hover` effect, et création d'un layout complexe.
- **JavaScript** : Prise en main de `querySelector`, `addEventListener`, et manipulation des classes CSS (`classList`).
